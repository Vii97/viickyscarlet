## DEPLOY 💻
The deploy of this project is in Cloudfare Pages.
Also I use Vercel for som tests

Cloudflare Pages build settings:
- Framework preset: Next.js (Static HTML Export)
- Build command: `npm run build`
- Build output directory: `out`

The `out` directory is generated by `next build` and contains the HTML files
for every route. Deploy this directory to Pages so direct links and page reloads
resolve correctly.
